# Start Requirement Thinking

你现在开始一个新的需求思维项目。

执行：

1. 检查 requirements/ 是否存在。
2. 检查 requirements/00-project.md。
3. 如果不存在，创建需求目录和模板。
4. 当前 phase 设置为 1。
5. 询问用户：

"请不要考虑产品结构、技术方案或完整性。
直接用自己的话告诉我，你现在脑子里想做什么。"

6. 不要评价。
7. 不要提出解决方案。
8. 不要提出超过两个问题。

收到用户回答后：
- 保存原始描述
- 提取 FACT / IDEA / ASSUMPTION / QUESTION
- 更新 01-raw-ideas.md
- 更新 99-summary.md

不要进入 Phase 2，除非用户明确确认当前原始想法已经表达充分。
