# Value / WHY (深层)

## 价值层级（2026-08-14 确认）

用户真正想获得的结果，按优先级：

1. **做饭不再纠结**（PRIMARY）
   - 核心价值：显著降低每天"决定吃什么"的决策负担
2. **更加健康**（SECONDARY）
   - 应用作为"专业知识担当"，把关健康度

## 辅助机制

- **灵活度滑块**（IDEA，CONFIRMED）
  - 用于解决"重样"问题：让用户自己决定菜谱的重复/新鲜程度
  - 把"变着吃"的控制权交给用户，而不是应用硬性规定

## 未来可拓展点

- **满意度反馈闭环**（FUTURE, FE-004）
  - 某次菜大受好评 → 用户反馈给应用 → 未来提高对应决策的满意度
  - 本质：让应用从"正确推荐"走向"推荐家人满意的菜"

## Feature vs Value 区分

- Feature：多因素匹配、刷新、规划、滑块
- Value：**做饭不再纠结**（主要）、**更健康**（次要）
