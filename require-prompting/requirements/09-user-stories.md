# User Stories

## v2（2026-08-14，按用户反馈拆分细化）

### 成员偏好（配置一次，决策前可开关）

### US-01 成员偏好管理
作为**家庭掌勺人**
我希望**录入并维护每个家庭成员的偏好与禁忌（配置一次、后续很少更改）**
以便**推荐时照顾每个人的口味与禁忌**

### US-02 决策前启用/停用成员偏好
作为**家庭掌勺人**
我希望**决策前勾选启用/停用某个具体成员的偏好**
以便**只针对当天实际用餐的成员做推荐**（例如某人不在家吃）

### 料理偏好（决策前勾选，可缓存复用）

### US-03 料理偏好设置
作为**家庭掌勺人**
我希望**决策前勾选料理手段与料理时间偏好**
以便**结果符合我今天能用的做法和时间**

### US-04 料理偏好方案缓存
作为**家庭掌勺人**
我希望**把常用的一套料理偏好组合保存为方案，下次直接调出复用**
以便**每次决策前不用重复勾选**

### 综合决策

### US-05 自由文本需求输入
作为**家庭掌勺人**
我希望**决策前用直白语言描述当前需求**（如"今天想吃清淡点""来点下饭的"）**并加入决策因素**
以便**结果更贴合当天的临时想法**

### US-06 权重设置（正式功能）
作为**家庭掌勺人**
我希望**在偏好页面与决策页能调整各决策因素的权重**
以便**测试并调出合适的权重组合**；预设档（"更健康/更美味"）延后（→ FE-010）

### US-07 综合决策
作为**家庭掌勺人**
我希望**应用综合考虑启用的成员偏好、料理偏好、自由文本输入、权重后给出推荐**
以便**拿到的结果全家人能吃且都倾向**

### 生成与展示

### US-08 按数量生成菜谱
作为**家庭掌勺人**
我希望**指定一次生成几道菜，获得对应数量的菜谱**
以便**一次拿到够吃的选择**

### US-09 再来一个（追加生成）
作为**家庭掌勺人**
我希望**在已有结果上点"再来一个"，不断叠加生成新菜**
以便**在现有基础上继续扩展选择**（替代原"刷新换菜"方案）

### US-10 固定格式展示
作为**家庭掌勺人**
我希望**菜谱按固定格式清晰展示**
以便**供用户参考时信息一目了然**

### 菜谱池

### US-11 手动新增菜谱
作为**家庭掌勺人**
我希望**手动把一道菜（食材、做法、时间、手段等标签）加入菜谱池**
以便**收录自己会做的菜，扩大可选范围**
