# Experience / 用户体验旅程

## 最小旅程（初版，2026-08-14）

```
触发：到点/想做菜，需要决定吃什么
  ↓
动作：打开应用 →（偏好早已录入）→ 选择模式（即时生成 / 规划一周）→ 生成
  ↓
响应：得到菜谱（含为什么适合你的依据）
  ↓
决策：满意 → 照着做；不满意 → 刷新换一个
  ↓
结果：纠结解决，吃得健康不重样
```

## 用户识别出的风险点（FACT）

1. **录入设计**：用户录入的信息层面需要设计好，并具备良好拓展性，
   以应对未来实际使用后出现的、真实的更需要的决策因素。
2. **不满意问题**：得不到满意菜谱是真实存在的风险；
   这是"决策调优"的重点，未来需要根据用户反馈调优，
   可能涉及决策因素占比的参数、甚至建模。
3. **知识正确性**：知识库层面能否处理好正确的知识还需考虑，
   最担心得到**错误的搭配或推荐**。
