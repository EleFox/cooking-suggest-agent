# Requirements / 需求清单

## 需求列表（v2，2026-08-14 按用户反馈修订）

### REQ-01 成员偏好（P0，最重要，但可选）
- 录入/编辑/查看多个家庭成员
- 每人独立：偏好、禁忌
- 配置一次、后续很少更改
- **决策前可勾选启用/停用某个成员的偏好**
- **成员数可为 0（决策引擎需兼容无成员偏好的情况）**

### REQ-02 料理偏好（P0，最重要）
- 料理手段（煎炒、凉拌、油炸…）
- 料理时间（固定时间区间 或 模糊词）
- **决策前每次勾选；可保存偏好组合为方案，下次直接复用（缓存）**

### REQ-03 决策引擎（P0）
- 硬约束（禁忌）过滤 + 软约束（偏好/时间/健康/时令）加权排序
- 偏好设置为决策重点
- **新增：决策前自由文本需求输入（直白语言）作为额外决策因素**
- **新增：权重设置页为正式功能（可调各因素权重）；"更健康/更美味"等预设档延后（FE-010）**

### REQ-04 即时生成（P0，必须）
- **指定生成数量 n，一次获得 n 道菜**
- 固定格式展示（规避生成管控）

### REQ-05 追加生成（P1，替代原刷新换菜）
- "再来一个"按钮，在已有结果上不断叠加生成新菜
- （原 REQ-05 刷新换菜方案已废弃，由本需求替代）

### REQ-06 菜谱黑名单 + 偏好度（P2，不急）
- 彻底拉黑某菜
- 设置菜偏好程度

### REQ-07 餐次规划（P2，不着急）
- 按勾选餐点生成一周/两周规划

### REQ-08 知识库（内置，不扩充）
- 时令知识参与决策（P1）
- 健康营养知识参与决策（P2，往后）
- 营养知识**不需要**扩充能力（CONFIRMED）

### REQ-09 菜谱池（P1）
- 内置预标注菜谱（食材/调料/过敏原/手段/时间/时令/营养标签）
- **新增：手动新增菜谱能力（US-11）**

### REQ-10 使用记录（P2，延后）
- 记录使用历史，可查看

### REQ-11 固定格式展示（P0，输出必需）
- 菜谱按固定格式输出

## 优先级汇总

| 级别 | 需求 |
|------|------|
| P0 必须 | REQ-01 成员偏好、REQ-02 料理偏好、REQ-03 决策引擎、REQ-04 即时生成、REQ-11 固定格式展示 |
| P1 重要 | REQ-05 追加生成（先做）、REQ-08 时令部分、REQ-09 菜谱池 |
| P2 延后 | REQ-06 黑白名单+偏好度、REQ-07 餐次规划、REQ-08 健康部分、REQ-10 使用记录 |
