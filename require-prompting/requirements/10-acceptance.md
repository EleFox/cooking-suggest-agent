# Acceptance Criteria

## 草稿（v1，2026-08-14，Given / When / Then）

### AC-US-01 成员偏好管理
- Given 我是掌勺人
- When 我录入一个新成员并设置其偏好与禁忌
- Then 该成员出现在成员列表中，且后续决策会读取其偏好与禁忌

### AC-US-02 启用/停用成员偏好
- Given 家庭成员列表中有若干成员
- When 决策前我停用了某成员
- Then 决策结果不受该成员偏好与禁忌的影响

### AC-US-03 料理偏好设置
- Given 决策页可设置料理偏好
- When 我勾选了料理手段与料理时间
- Then 生成结果只包含符合该手段与时间范围的菜谱

### AC-US-04 料理偏好方案缓存
- Given 我已保存过一套料理偏好组合为方案
- When 我在下次决策时调出该方案
- Then 料理偏好自动应用，无需重新勾选

### AC-US-05 自由文本需求输入
- Given 决策页有自由文本输入
- When 我输入"今天想吃清淡点"并生成
- Then 结果倾向于清淡类菜谱，且不违反任何启用的禁忌

### AC-US-06 权重设置
- Given 偏好/决策页有权重设置
- When 我调整某因素权重后重新生成
- Then 结果的排序/内容随权重变化而相应变化

### AC-US-07 综合决策
- Given 多个成员的偏好、禁忌、料理偏好、权重均已配置
- When 我点击生成
- Then 结果不包含任何启用成员的禁忌，且按权重综合排序

### AC-US-08 按数量生成
- Given 决策页
- When 我指定生成 3 道菜
- Then 一次返回 3 道不重复的菜谱

### AC-US-09 再来一个（追加生成）
- Given 已有生成结果
- When 我点击"再来一个"
- Then 追加一道新菜，且不与已有结果重复

### AC-US-10 固定格式展示
- Given 生成结果
- When 展示菜谱
- Then 每道菜以统一字段呈现（名称/食材/做法/时间/手段等），供参考时一目了然

### AC-US-11 手动新增菜谱
- Given 菜谱池
- When 我手动新增一道菜并填写标签
- Then 该菜进入菜谱池，可在后续决策中被推荐
