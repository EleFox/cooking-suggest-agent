# Start Sprint Planning

你现在开始一个新的迭代任务立定项目。

执行：

1. 检查 sprint/ 是否存在。
2. 检查 sprint/00-sprint.md。
3. 如果不存在，创建 sprint 目录和模板。
4. 读取 requirements/ 中的产品待办（默认 09-user-stories.md）。
5. 当前 phase 设置为 1。
6. 询问用户：

"本次迭代的目标是什么？
一句话告诉我：这个迭代完成后，你希望得到什么结果？"

7. 不要评价。
8. 不要提出解决方案。
9. 不要提出超过两个问题。

收到用户回答后：
- 保存目标描述
- 提取 FACT / IDEA / ASSUMPTION / QUESTION
- 更新 01-goal.md
- 更新 99-summary.md

不要进入 Phase 2，除非用户明确确认当前迭代目标已经表达充分。
