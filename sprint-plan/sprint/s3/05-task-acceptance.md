## T1 · 成员管理页面

### AC-T1-1 新增成员

- Given 用户进入成员管理页面（独立路由）
- When 新增一个成员并配置其偏好与禁忌，保存
- Then 该成员出现在成员列表中，且配置被持久化

### AC-T1-2 编辑成员

- Given 成员列表中存在某成员
- When 修改该成员信息或偏好/禁忌并保存
- Then 修改生效并持久化

### AC-T1-3 删除成员

- Given 成员列表中存在某成员
- When 删除该成员
- Then 成员从列表移除，且不再出现在设置页成员启停区

### AC-T1-4 0 成员空态

- Given 尚未录入任何成员
- When 进入成员管理页面
- Then 空态展示无报错，系统其他功能不受影响

## T2 · 决策设置页成员启停

### AC-T2-1 启用/停用勾选

- Given 存在已录入成员，用户进入料理偏好设置页
- When 勾选启用/停用某成员
- Then 勾选结果生效并用于本次决策

### AC-T2-2 停用成员不参与

- Given 某成员已被停用
- When 用户发起决策
- Then 该成员的偏好与禁忌不影响本次决策结果

### AC-T2-3 0 成员情况

- Given 无成员数据
- When 进入料理偏好设置页
- Then 成员区空置、不阻塞，设置页其他功能正常使用

## T3 · 成员偏好联调决策接口

### AC-T3-1 启用成员参数传入

- Given 用户启用部分成员并发起决策
- When 决策请求发出
- Then 请求携带启用成员的偏好/禁忌参数

### AC-T3-2 停用成员参数不传入

- Given 某成员已被停用
- When 决策请求发出
- Then 请求不携带该成员的参数

### AC-T3-3 沿用既有决策链路

- Given 决策接口已有实现（S1/S2 链路）
- When 传入成员偏好参数
- Then 接口按已有逻辑处理，Agent 端决策逻辑不变

## T4 · 手动新增菜谱

### AC-T4-1 新增菜谱

- Given 用户进入新增菜谱页面（独立路由）
- When 填写菜谱信息并保存
- Then 该菜进入菜谱池并持久化

### AC-T4-2 新增菜可被推荐

- Given 菜谱池中存在手动新增的菜
- When 发起决策（条件满足时）
- Then 该菜可出现在决策结果中

## T5 · 菜谱维护

### AC-T5-1 查看已增菜谱

- Given 存在手动新增的菜谱
- When 进入菜谱维护页
- Then 展示已增菜谱列表

### AC-T5-2 编辑菜谱

- Given 存在某道已增菜谱
- When 修改其信息并保存
- Then 菜谱池中该菜信息相应更新

### AC-T5-3 删除菜谱

- Given 存在某道已增菜谱
- When 删除该菜
- Then 该菜从菜谱池移除
