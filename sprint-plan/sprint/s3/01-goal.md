# Sprint Goal / 迭代目标（S3）

## One Line Goal

补齐"全家能吃且倾向"的最后一块：成员偏好可录入维护、决策前可启停并生效于决策结果；菜谱池支持手动扩充。

## 目标解读

- "全家能吃" = 启用成员的禁忌不出现在结果中（硬约束生效，由 Agent 端过滤，本轮验证联调）
- "且倾向" = 启用成员的偏好影响结果排序（软约束生效）
- "手动扩充" = 掌勺人可把自己的菜加入菜谱池，扩大可选范围

## 衡量方式（DRAFT）

- 迭代结束时演示：录入成员 → 配置偏好/禁忌 → 决策前启停 → 生成结果体现成员因素（接口联调验证）
- 手动新增一道菜后可进入菜谱池并被决策推荐

## 范围约束（CONFIRMED，2026-09-09，延续 S2）

- 仅讨论 web + service 端；Agent 端内容由其他团队负责，本迭代不涉及
- service 只把成员偏好参数传给已有决策接口联调，不改 Agent 决策逻辑
