# Risk / 风险清单（DRAFT）

| # | 风险 | 影响 | 可能性 | 缓解 |
|----|------|------|--------|------|
| RK-01 | 双服务 + 反向调用联调复杂度（首迭代无先例） | 联调阻塞 | 中 | T-A1 骨架内先验证反向调用通道，技术选型集中、易替换 |
| RK-02 | Agent 规则化决策结果"倾向/满意度"不达标（默认权重） | 核心价值验证失败 | 中 | 权重参数化（默认值）；评估标准定为"能吃且倾向"而非完美 |
| RK-03 | 0 成员下硬过滤验证依赖偏好/时间条件，禁忌能力未验证 | 禁忌 100% 不撞验证延后 | 低-中 | 查询 API 硬过滤参数机制保留，后续成员迭代再验证 |
| RK-04 | 超时/迭代上限导致体验问题 | 决策流程中断或不稳定 | 低-中 | Agent 自限时限 + 同步超时兜底 + 无结果/超时提示 |
| RK-05 | 技术栈未定，骨架验证后可能返工 | 返工成本 | 中 | 骨架仅搭最小结构，选型决策点集中、易替换 |
| RK-06 | 设计稿冻结与前端实现偏差 | 联调返工 | 低 | T-U2 一次出稿含评审冻结 |
| RK-07 | 单人 2 周内四条线+架构并行，专注力分散 | 单点延误 | 中 | 串行优先关键路径，设计/种子线并行缓冲 |

## 需缓冲项

- T-A1 骨架（双服务 + docker + 反向调用验证）：技术选型不确定性，预留 0.5 天缓冲
