## 架构变更影响（CONFIRMED，2026-08-22）

- 决策核心从"单体决策引擎"迁移至 **Agent 服务**（规则化）
- 接口服务新增两个对外接口（供 Agent 反向调用）：
  - 菜谱查询 API：按条件过滤（含硬过滤）/关键字/去重，返回菜谱摘要列表
  - 菜谱详情 API：按菜谱 id 返回 MD 全文
- 接口服务保留决策 API：接收前端决策输入 → 透传 Agent → 接收结果 → 组装固定格式 Markdown 返回
- 边界约定：docker-compose 同机部署；同步方案 C + 超时兜底；Agent 端自限时限；Agent 可能返回"无结果"
