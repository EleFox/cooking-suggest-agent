# 设计规范（Design Spec）

> 更新：2026-08-21

## 1. 设计目标

本规范为移动端 UI 定义统一的视觉语言与交互规范，供 Penpot 设计文件与前端实现（shadcn/ui + Radix UI）对齐使用。

**风格关键词**：简约（Minimal）、克制、温暖、可信赖。拒绝装饰性冗余，让"信息与决策"本身成为主角。

---

## 2. 画布与响应式

- **基准画板尺寸**：750px × 1334px（移动端，@2x 视觉稿）。
- **内容安全区**：左右各留 32px 边距（`space-8`），顶部状态栏区域预留 44px，底部预留安全区。
- **自适应**：单列纵向流式布局为主；卡片、按钮、输入框等弹性宽度组件需在 320px ~ 750px 宽度范围内自适应伸缩，不留死空间。
- **栅格**：所有尺寸、间距遵循 **4px 网格**（4 / 8 / 12 / 16 / 24 / 32 / 48…）。
- **触控目标**：主操作（按钮、开关、可点卡片）高度 ≥ 88px（44pt），点按区域不小于该尺寸。

---

## 3. 色彩（Color）

> 语义化命名，绑定设计 Token；严禁在形状上硬编码色值。

| Token                      | 用途              | 参考色值             |
| -------------------------- | --------------- | ---------------- |
| `color.bg`                 | 页面背景            | `#FAF7F2`（暖白，柔和） |
| `color.surface`            | 卡片 / 输入框 / 组件底色 | `#FFFFFF`        |
| `color.primary`            | 主操作、强调          | `#E86A3C`        |
| `color.primary.foreground` | 主按钮文字           | `#FFFFFF`        |
| `color.primary.soft`       | 选中态浅底           | `#FCE9E0`        |
| `color.text`               | 正文              | `#2D2A26`        |
| `color.text.muted`         | 次要文字 / 说明       | `#8A857E`        |
| `color.border`             | 分割线 / 描边        | `#E8E2D8`        |
| `color.success`            | 成功              | `#4C9A5F`        |
| `color.warning`            | 提示              | `#D99A2B`        |
| `color.error`              | 错误 / 冲突警示       | `#C94A3C`        |

**对比度**：正文 `#2D2A26` on `#FAF7F2` 对比度 ≥ 7:1（AAA）；`text.muted` 仅用于非关键信息，且不低于 4.5:1。错误 / 硬性约束类信息一律用 `error` 色，不得弱化。

---

## 4. 字体排印（Typography）

- **字体族**：系统无衬线（`PingFang SC` / `HarmonyOS Sans` / `Roboto`），保持移动端原生观感。
- **字号阶梯**（间距、行高遵循 4px 网格）：

| Token              | 字号  | 行高  | 字重  | 用途        |
| ------------------ | --- | --- | --- | --------- |
| `type.display`     | 32  | 40  | 700 | 页面大标题     |
| `type.h1`          | 24  | 32  | 600 | 区块标题      |
| `type.h2`          | 20  | 28  | 600 | 卡片标题      |
| `type.body`        | 16  | 24  | 400 | 正文        |
| `type.body.strong` | 16  | 24  | 600 | 强调正文      |
| `type.caption`     | 13  | 20  | 400 | 辅助说明 / 标签 |
| `type.label`       | 14  | 20  | 500 | 表单标签 / 按钮 |

- 中英文混排时统一基线对齐；数字与单位使用等宽数字风格保持整齐。

---

## 5. 间距（Spacing）

统一使用 4px 网格刻度：`space-1=4` `space-2=8` `space-3=12` `space-4=16` `space-6=24` `space-8=32` `space-10=40` `space-12=48`。

- 页面左右边距：`space-8`（32px）。
- 卡片与卡片间距：`space-4`（16px）。
- 卡片内边距：`space-6`（24px）。
- 相邻独立区块间距：`space-8` 及以上。
- 分组标题与其内容：`space-4`。

---

## 6. 圆角与阴影（Radius & Elevation）

- **圆角**（遵循 shadcn/ui 风格）：
  - `radius-sm`：8px —— 标签 / 小型控件
  - `radius-md`：12px —— 输入框 / 按钮
  - `radius-lg`：16px —— 卡片
  - `radius-full`：999px —— 胶囊按钮 / 数量选择器 / 头像
- **阴影**：克制，仅用于悬浮层（底部抽屉、弹层）：
  - 卡片默认无阴影，仅用 `border` 分隔；
  - 抽屉 / 弹层使用 `0 -8px 24px rgba(45,42,38,0.12)`。

---

## 7. 组件规范

> 全部复用 shadcn/ui + Radix UI 组件，图标用 Lucide React；本规范约束其在设计稿中的通用形态。

### 7.1 按钮（Button）

- **主按钮**（Primary）：`color.primary` 底、白字、`radius-md`、高 88px、圆角 16px、全宽（表单主导操作）。
- **次按钮**（Secondary / Outline）：白底 + `color.border` 描边，主文字色。
- **胶囊按钮**（Pill）：轻量操作，`radius-full`。
- **图标按钮**（Icon）：仅图标，触控区 ≥ 88px。
- **状态**：默认 / 悬停（加深 5%）/ 按下（再加深）/ 禁用（40% 不透明度，`text.muted`）。

### 7.2 开关（Switch）

- 用于二选一启停选项。开启 `color.primary`，关闭 `color.border`；高度 64px、宽度 104px（触控友好）。

### 7.3 复选 / 多选（Checkbox / Chip）

- 多项选择使用 **Chip 胶囊多选**：未选 = 白底 + 描边；已选 = `color.primary.soft` 底 + 主色文字 + 主色描边。
- 触控高度 ≥ 88px，间距 `space-3`。

### 7.4 输入框（Input / Textarea）

- 白底、`color.border` 描边、`radius-md`、内边距 `space-4`。
- 多行输入使用 Textarea，附带提示占位。
- 状态：默认 / 聚焦（主色描边 + 2px 主色光环）/ 错误（`error` 描边 + 错误提示文字）。

### 7.5 数量选择器（Stepper）

- 用于选择数量：左右 `-` / `+` 图标按钮 + 中间数字，胶囊形态。

### 7.6 底部抽屉（Sheet）

- 用于次级操作，从底部滑出，圆角 `radius-lg` 顶部、带遮罩。

### 7.7 加载 / 空状态

- **加载**：骨架屏（Skeleton）或主色转圈 Spinner + 文案。
- **空状态**：居中图标（Lucide）+ 主文字 + 次按钮引导操作。

### 7.8 信息卡片（Info Card）

- 信息一栏式排列，字段一致、层级清晰：
  - 标题（`h2`）
  - 标签行（`caption` + 浅底 Chip）
  - 列表 / 正文（`body`）
  - 底部元信息行（图标 + 文字）
- 卡片可附带列表底部的主操作入口。

---

## 8. 交互状态

所有可交互组件必须覆盖并设计以下状态：

- 默认（Default）
- 悬停（Hover）
- 聚焦（Focus）
- 激活 / 选中（Active / Selected）
- 禁用（Disabled）
- 加载中（Loading）
- 空状态（Empty）
- 错误（Error）
- 成功（Success）

---

## 9. 图标（Icons）

- 一律使用 **Lucide React** 图标，若缺少符合需求的图标，然后提出来让我决定如何处理。
- 图标语义化使用，与文字、状态保持一一对应；选中态等场景不可仅依赖颜色区分，需配合图标 / 描边。

---

## 10. 可访问性（Accessibility）

- 正文与背景对比度 ≥ 4.5:1（正文达到 7:1）。
- 触控目标 ≥ 88px（44pt）。
- 颜色不作为唯一信息载体（如选中状态同时用图标 / 描边区分）。
- 表单控件带明确 label 与错误提示。

---

## 11. 设计决策记录

- 具体色值、字号为 v1 建议值，正式落地前需经人工确认后再写入 Penpot Token。
- 后续若产生新设计决策（如新增组件、调整 Token），回填本规范与对应 Token。

## 12. 结果页设计决策（REQ-04 / REQ-05）

- 即时生成结果采用单列卡片列表，保留已生成菜谱，避免将追加生成误解为刷新替换。
- 卡片左侧使用几何化菜品图标占位，后续接入真实菜品图片时保留相同的 180px 视觉区域。
- 卡片固定展示菜名、主要食材、预估时间和难度标签；难度同时使用文字与颜色区分，不依赖颜色单独传达信息。
- “查看详情”为卡片主操作；“不满意”为次级反馈操作，使用描边按钮降低误触和视觉竞争。
- “再来一道”固定放在结果列表末尾，保留当前结果并追加新菜谱，不覆盖已有内容。
- Penpot 本地结果页当前使用 `result-page-blue-v1` Token 集。由于 Token 路径不允许同时存在父级 `color.primary` 与子级 `color.primary.foreground`，本页使用 `blue.foreground` 与 `blue.soft` 表达对应语义。
- 结果页顶部仅保留明确的结果标题与说明，移除语义不明的栏目标题和数量徽标；首张卡片在状态栏安全区之后开始布局。
- 结果页主题调整为常见蓝色系：页面与卡片使用白色，主色使用 `#2563EB`，浅色强调使用 `#EFF6FF`。
- 卡片图标占位使用无边框圆角方形；卡片操作按钮缩小为 64px 的视觉控件，同时保留 88px 透明触控区域以满足可访问性要求。
- 卡片底部不再展示“查看详情”按钮，整张卡片作为详情入口；“不满意”改为卡片右上角红色 `×` 控件，并保留独立的 88px 触控区域。
- 卡片摘要信息统一采用“字段标签 + 内容值”的布局，包含“需要食材”“所需时间”和“烹饪难度”；食材使用中文顿号 `、` 分隔。
- 删除控件采用吸附卡片顶部和右侧的左下四分之一圆形，中心使用白色 `×`，红色背景用于强化删除语义。

## 13. 料理偏好设置页与方案页设计决策（S2 / US-03、US-04）

> 本页沿用 `result-page-blue-v1` Token 集（蓝色系），与结果页视觉一致。

### 13.1 页面拆分

- 每个画板独占一个 Page：`preference-settings`（料理偏好设置页）、`preference-schemes`（偏好方案管理页）；结果页保留在 `Blank Mobile 750x1334`。
- 画板命名：`preference-settings-screen`、`preference-schemes-screen`（750×1334）。

### 13.2 料理偏好设置页

- 标准表单布局：标题 →「料理手段」分组（标签 + Chip 多选）→「料理时间」分组（标签 + Chip 多选）→「生成数量」分组（标签 + Stepper 数量选择器）→「我的方案」入口 → 底部主操作「查看菜谱」。
- 「生成数量」为 Stepper 数量选择器（§7.5）：全宽胶囊（白底 + `border` 描边 + `radius-full`，视觉高度 44px），左右为 `−` / `+` 按钮区（各 88px 宽，触控热区可扩展至 ≥88px 高）、中间为数字输入区（默认值 `1`，可直接输入或点按按钮增减）。
- **每个分组标签紧随其选项组之上**（修复此前标签与选项错位问题）；分组内标签→选项间距 `space-3`（12px），分组间间距 `space-8`（32px）。
- 移除页面级副标题/说明小字。
- 选项采用 Chip 胶囊多选（`radius-full`，高 44px）：未选 = 白底 + `border` 描边 + 正文色；已选 = `soft` 底 + `primary` 文字 + `primary` 描边。示例默认选中「煎」「快手（≤20分）」。（注：Chip 视觉高度为 44px，按用户要求缩小；实现时触控热区可按可访问性要求扩展到 ≥88px。）
- 「我的方案」为导航入口卡片（白底 + `border` 描边，`radius-lg`，右侧 `›`），点击进入方案页。
- 主操作「查看菜谱」为全宽 `primary` 底主按钮（`radius-lg`，高 88px），固定于底部安全区。
- 「保存方案」为次级（Outline）全宽按钮（白底 + `primary` 描边 + `primary` 文字，`radius-lg`，高 88px），置于「查看菜谱」上方（间距 `space-3`）。点击后自动保存当前偏好组合并跳转到「偏好方案」页。

### 13.3 料理偏好方案页

- 标题「偏好方案」+ 方案卡片列表 + 底部主操作「新建方案」（固定于底部）。
- 方案卡片（白底 + `border` 描边，`radius-lg`）：卡片头 = 方案名 + 「默认」标签（默认态 `soft` 底 + `primary` 文字；非默认态白底 + `muted` 文字）；摘要行（`caption`，`muted`）；操作行。
- 卡片操作统一为**文字按钮并右对齐**：`调出` / `编辑`（`primary`）、`删除`（`error`），移除图标按钮与左对齐胶囊。触控高度 88px。
- 移除页面级副标题/说明小字。

## 14. 成员管理与菜谱管理设计决策（S3 / US-01、US-02、US-11）

> 全部沿用 `result-page-blue-v1` Token 集与既有蓝色系视觉。每个页面独占一个 Page（同一页面的不同状态可共页）。

### 14.1 页面拆分

- 新增 4 个 Page：`member-management`（成员管理）、`member-form`（成员表单）、`recipe-management`（菜谱管理）、`recipe-form`（菜谱表单）。
- 画板命名：`<page>-screen`（750×1334）；成员管理页附加空态画板 `member-management-screen-empty`（位于主画板右侧 x=850）。
- T2 成员启停区直接改造既有 `preference-settings` 页画板，不新建 Page。

### 14.2 成员管理列表页（T1 / US-01）

- 无分页、无搜索；卡片式简单列表。
- 成员卡片（白底 + `border` 描边，`radius-lg`，内边距 24）：
  - 头行 = 姓名（`h2` 20/600）。
  - 「偏好」分组（20/600）：子标签 **食材 / 口味**（14/500 `muted`）+ 各自 Chip 行。
  - 「食材禁忌」分组（20/600）：Chip 行。
  - **展示卡片上的 Chip 一律为"已选"样式**（`soft` 底 + `primary` 文字 + `primary` 描边）——卡片展示的是已配置项，不出现未选态。
  - **成员管理不展示料理手段**（手段属于料理偏好，不属于成员档案）。
  - **操作按钮组置于卡片底部、右对齐**（与方案卡片一致）：`编辑`（`primary`）、`删除`（`error`），14/500，触控高度 88px。
- 底部主操作「新增成员」固定于底部安全区（`primary` 底、`radius-lg`、高 88）。
- 空态（AC-T1-4）：居中 Lucide 形态人形图标 + 主文字「还没有家庭成员」+ 说明文字 + 次按钮（Outline）「新增成员」。

### 14.3 成员表单页（T1 / US-01，新增/编辑共用）

- 偏好与禁忌**不用固定选项规范**，采用「列表 + 输入框」模式：
  - 列表 = 该成员已保存的条目，以**可移除标签 Chip** 展示（`soft` 底 + `primary` 描边 + 尾部 `×` 移除控件，`radius-full`、高 44）。
  - 录入行 = Input（`radius-md`、高 88）+「确认」按钮（`primary` 底、`radius-md`、160×88），可连续新增条目。
  - **占位文案必须为明确示例**（如：牛肉 / 如：微辣 / 如：香菜），禁止"爱好××、不吃××"类引导，避免误导输入。
- 偏好**拆分为食材与口味两个独立录入**（各自列表 + 录入行）；禁忌 = **食材禁忌**（仅食材，单组列表 + 录入行）。
- **成员表单不含料理手段**（手段在料理偏好设置页勾选，不随成员维护）。
- 字段顺序：姓名（Input）→ 偏好·食材 → 偏好·口味 → 食材禁忌。
- 底部主操作「保存」固定于底部安全区。编辑模式复用同一画板结构（仅标题与回填值不同，实现期处理）。

### 14.4 菜谱管理列表页（T5 / US-11）

- 顶部搜索栏：白底 + `border` 描边 + `radius-md`、高 88，内含 Lucide `Search` 形态图标（圆环 + 45° 手柄，`muted` 色）与占位文字「搜索菜谱」。
- 分页采用滚动加载，不在静态稿中体现；列表即菜谱卡片流。
- **菜谱卡片与结果页（推荐页）卡片保持一致**，逐像素复刻其几何：图占位 180×180（`soft` 底、`radius` 24）、标题 20/600、字段标签 13/500 `muted`、食材值 16/400 正文色、时间 / 难度值 16/500；**难度值颜色跟随推荐页语义**（简单 = `success` 绿、一般/困难 = `primary` 蓝）。
- 卡片交互语义在管理页适配 T5：
  - 右上红色删除角标（66×66，左下 1/4 圆，白 `×`，含 88px 透明触控区）= **从菜谱池删除**；
  - 整卡点按 = **进入编辑**（复用菜谱表单页）。
- 底部主操作「新增菜谱」固定于底部安全区。
- **菜谱管理入口位于推荐页（`recipe-suggestion`）**：「再来一道」下方全宽 Outline 按钮「菜谱管理」（686×96、`radius-lg`、文字 36/600 `primary`）。

### 14.5 菜谱表单页（T4 / US-11，新增/编辑共用）

- 字段顺序（用户确认）：
  1. 名称（Input，`radius-md`、高 88）；
  2. **主要食材**：同成员表单的「列表 + 录入行」模式（可移除标签 Chip + Input +「确认」）；
  3. 料理手段（Chip 多选，紧随食材之下）；
  4. 预估时间（Stepper：全宽胶囊、视觉高 44、左右 88px 触控区、中值 + 单位「分钟」）；
  5. **难度**：选项 简单 / 一般 / 困难（Chip 样式、**单选语义**，选中项 `soft` 底 + `primary` 描边）；
  6. 做法（Textarea，高 240，**最后一条表单元素**）。
- 底部主操作「保存」固定于底部安全区。

### 14.6 料理偏好设置页成员启停区（T2 / US-02）

- 「成员」分组置于**「生成数量」与「我的方案」之间**（成员为不固定长度的选项，不顶头显示；决策顺序：为谁做 → 怎么做 → 做多少）。
- 头行 = 「成员」（20/600），不再放置小号入口链接。
- 成员行 = **带边框块**（白底 + `border` 描边、`radius-lg`、高 88、水平内边距 24）：左侧姓名（16/500，与正文一致）、右侧 Switch（缩小为 **80×44**、滑块 36×36：开 = `primary`、关 = `border`），以块级边框弥补信息密度。默认全员启用；示例中「孩子」为停用态。
- 成员行底部为**全宽 Outline 按钮「管理成员」**（高 88），作为成员管理页入口，与成员数据联动。
- 数据联动：成员管理中删除的成员不再出现在成员区；**0 成员时成员区仅保留头行或整区不渲染，不阻塞设置页其他功能**（AC-T2-3）。
